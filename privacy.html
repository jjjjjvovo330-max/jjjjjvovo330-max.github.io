2. 검진 안내 입력과 기기 저장

출생연도·성별·가입 유형은 기기 안에서 예상 규칙을 계산하는 데 사용하며, 앱 코드가 조회 서버나 광고 요청에 전달하지 않습니다. 조회 입력 자체를 영구 저장하지 않습니다. 검진 결과 수치·병력·주민등록번호는 받지 않습니다.

가족 별칭·출생연도·성별·가입 유형·예정일·완료 표시와 준비물 체크는 이용자가 선택하면 이 기기의 웹 저장소(localStorage)에 저장됩니다. 가족 본인 또는 필요한 법정대리인의 동의를 받고 별칭으로 관리하세요. 운영자는 이 기기 기록을 조회하는 서버나 동기화 계정을 제공하지 않습니다.

3. 보관·삭제

가족 카드의 개별 삭제, 저장 정보 전체 삭제, 브라우저 사이트 데이터 삭제 또는 Android 앱 데이터 삭제로 기기 기록을 지울 수 있습니다. 앱 제거 시 해당 앱 저장 데이터가 제거됩니다. Android 앱의 자동 백업·기기간 전송 제외 규칙을 적용하지만 기기 제조사·사용자가 별도 수행하는 복사·백업 전체를 통제하지는 않습니다. 암호화 의료기록 보관함이 아니므로 실명이나 민감한 병력을 입력하지 마세요.

문의 메일을 보내면 발신 주소와 문의 내용이 이메일 서비스(Gmail)에서 처리됩니다. 문의 대응에 필요한 동안 보관하고, 더 이상 필요하지 않은 정보는 삭제합니다. 법적 의무·분쟁 대응 등 보관 사유가 있으면 해당 목적에 필요한 기간을 적용합니다.

4. 웹 호스팅과 접속 정보

웹사이트는 GitHub Pages(GitHub, Inc.)를 통해 HTTPS로 제공합니다. 페이지를 받으려면 접속 IP 등 통신 정보가 호스팅 제공사에 전달됩니다. GitHub의 공식 안내에 따르면 Pages 방문자의 IP 주소는 로그인 여부와 관계없이 보안 목적으로 기록·저장됩니다. 운영자는 별도의 방문자 추적·분석 스크립트, 서버 건강정보 수집 API, 외부 폰트를 설치하지 않았습니다.

GitHub의 접속정보 보관은 제공 목적과 법적 의무에 따라 달라집니다. 운영자가 모든 호스팅 로그의 일괄 보관 기한을 정하거나 개별 로그 전체의 삭제를 보장하지 않습니다. 자세한 처리·권리행사 방법은 GitHub Pages 안내 및 GitHub 개인정보처리방침을 확인하세요.

5. Android 광고·동의 SDK

일반 웹페이지는 광고를 요청하지 않습니다. Android 앱에는 Google Mobile Ads Next-Gen SDK 1.7.0과 Google UMP 4.0.0이 포함되어 있습니다. 현재 출시 준비 설정에서는 운영 광고 요청을 차단하고 있습니다. 이후 광고 기능을 활성화하는 경우 배너만 사용하며 시작·전면·보상 광고를 사용하지 않습니다.

광고 SDK가 초기화·요청되는 경우 Google 및 광고 파트너가 광고 제공·측정·부정행위 방지 등을 위해 IP(대략적인 위치를 추정할 수 있음), 앱·광고 상호작용, 진단 정보, 광고 ID·앱 세트 ID 등 기기 식별자를 처리·공유할 수 있습니다. 포함된 SDK를 이유로 모든 기술정보 수집이 없다고 안내하지 않습니다. 출생연도·성별·가족 별칭·검진 예상 내용은 앱 광고 요청에 전달하지 않습니다.

앱은 UMP의 광고 요청 허용 상태를 확인한 뒤에만 광고 SDK 초기화를 허용합니다. SDK 초기화 자체가 네트워크 통신·사전 로드를 할 수 있습니다. 초기화 후 publisher first-party ID 해제 성공을 확인하고 배너 요청을 허용하지만, 이 설정이 모든 식별자·통신을 없앤다는 뜻은 아닙니다. Google 공개 문서상 SDK 전송에는 TLS가 사용됩니다.

동의 화면이 요구되는 지역에서는 동의·거부·옵션을 선택하고, 제공되는 ‘광고 개인정보 설정’에서 선택을 변경할 수 있습니다. 거부 후에도 Google이 허용하는 제한 광고 요청이 가능할 수 있어 전체 광고 끄기 기능과 다릅니다. Android 광고 개인정보 설정에서 광고 ID 초기화·삭제 등을 관리할 수 있습니다.

Google의 항목별 보관 기간은 서비스·보안·법적 의무에 따라 다르며 운영자가 Google 로그 전체를 직접 삭제할 수는 없습니다. 광고 ID 초기화·동의 철회는 모든 Google 데이터 삭제와 같지 않습니다. Google SDK 데이터 공개 안내, Google 개인정보처리방침, Google 보관 안내를 참고하세요.

6. 국외 처리

호스팅 접속정보는 GitHub의 서비스 제공·보안 목적으로 인터넷 통신 시 전송·처리되며 미국 및 GitHub·계열사·하위처리업체가 운영하는 국가에서 처리될 수 있습니다. 광고 기능이 허용되는 경우 Google 서비스도 미국 등 글로벌 인프라에서 위 기술정보를 처리할 수 있습니다. 국내 한정 처리라고 안내하지 않습니다. 처리국가·제공업체·보관 기준과 권리행사 절차의 최신 정보는 위 제공사 공개 정책을 따릅니다. 서비스에 불필요한 건강·가족 입력을 해당 업체에 별도 전송하는 기능은 두지 않았습니다.

7. 캘린더와 외부 링크

웹 일정 파일은 기기에서 만듭니다. Android는 이용자가 직접 선택한 예정일과 일반 제목 ‘건강검진 예정’만 캘린더 앱의 작성 화면에 전달합니다. 가족 별칭·출생연도·성별·검진 예상 내용은 전달하지 않으며 캘린더 읽기/쓰기 권한이나 자동 저장을 사용하지 않습니다. 사용자가 직접 저장한 뒤의 동기화·보관·알림은 해당 캘린더 서비스의 설정과 정책을 따릅니다.

공단 등 공식 외부 링크는 사용자가 선택하면 외부 브라우저로 열립니다. 로그인·신청 등 해당 사이트의 처리는 그 기관 정책을 따릅니다. 앱은 공단 계정이나 실제 개인 검진 이력을 조회하지 않습니다.

8. 권리행사와 변경

기기 기록은 앱·브라우저의 삭제 기능을 이용하세요. 운영자에게 열람·정정·삭제 등 개인정보 문의를 할 때는 위 이메일로 연락할 수 있습니다. 운영자가 보유하지 않은 기기 기록이나 제공사 로그에 대한 직접 접근·삭제에는 한계가 있어 해당 제공사의 절차를 안내할 수 있습니다. 서비스·SDK·처리방식 변경 시 이 페이지에 시행일과 변경 내용을 반영하고 필요한 고지·동의를 진행합니다.
